## Description

Deliver the main controller with ordered phase execution and condition-gated progression. Each phase only runs if the previous phase's condition is True:* Discovery -- detect cluster domain, StorageClass, and S3 config before any workloads are created

- Validation -- probe all external prerequisites (DB, Cache, Kafka, OIDC, S3) to confirm they are reachable
- Migrations -- run schema migration Jobs; blocks app deployment until DB schema is up to date
- Application -- create/update all application Deployments and Services
- Platform -- wire OpenShift integration (Routes, NetworkPolicies, ServiceMonitors, ConsoleLink)
Also includes: pause/resume via annotation, exponential backoff requeue, and Kubernetes Events on state transitions.

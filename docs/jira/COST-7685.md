## Description

Deliver migration Job management for Koku, ROS, and RBAC schemas, plus RBAC data seeding (bootstrap initial roles/permissions).* Jobs run sequentially in fixed order: Koku first, then ROS, then RBAC migration, then RBAC seeding

- Each Job has activeDeadlineSeconds: 600 (10 min) and backoffLimit: 3
- On Job failure, the operator retries the failed Job up to 3 times; if all retries are exhausted, set SchemaUpToDate=False with the failed Job name in the condition message and block phase progression
- Previously succeeded Jobs are not re-run
- On upgrades, run migrations before updating Deployments
- On all migrations and seeding complete, set SchemaUpToDate=True and transition status.phase from Migrating to Deploying

### Out of Scope

- Application Deployment creation

## Description

Deliver observability for both the operator and managed workloads:* Operator metrics -- expose controller-runtime metrics (costmanagement_reconcile_duration_seconds, costmanagement_reconcile_errors_total, costmanagement_component_ready, costmanagement_migration_duration_seconds) on /metrics endpoint with a dedicated Service and ServiceMonitor

- Application ServiceMonitors -- one per component that exposes a Prometheus endpoint (Koku API, MASU, Celery workers, ROS API, Kruize, RBAC, Gateway). Scrape interval and labels configurable
- PrometheusRules -- alerts with concrete thresholds: pod restart rate > 3 restarts in 15 min (CostManagementPodRestarting), reconciliation error rate > 5 errors in 10 min (CostManagementReconcileFailure), migration Job not complete within 10 min (CostManagementMigrationStalled), dependency condition False for > 5 min (CostManagementDependencyDown), Celery queue depth > 1000 for > 10 min (CostManagementCeleryBacklog)
- Kubernetes Events -- emit Events on the CostManagement CR for: phase transitions (PhaseChanged), migration completion (MigrationsComplete), secret rotation (SecretRotated), dependency failure (DependencyFailed), drift correction (DriftCorrected)

### Out of Scope

- Application-level business metrics (e.g., cost processing throughput), log aggregation, Grafana dashboards

## Description

Deliver Django key rotation triggered by setting annotation cost.redhat.com/rotate-secrets: "true" on the CostManagement CR.

On detecting the annotation, the operator:
1. Generates a new 50-character Django secret key (same spec as story 10)
2. Updates the Secret
3. Triggers a rolling restart of all Deployments that mount it by patching a cost.redhat.com/secret-hash annotation on their pod templates with the new Secret's content hash
4. After restart completes, removes the rotate-secrets annotation and emits a SecretRotated Event

Also deliver CA bundle combination: merge OpenShift service CA, proxy CA, and any user-provided CA certificates into a single ConfigMap mounted by all components that need TLS verification.


### Out of Scope* External service credential rotation (user's responsibility)

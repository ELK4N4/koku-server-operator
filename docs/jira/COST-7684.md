Deliver the Validation phase including secret resolution and connectivity probes:* Secret resolution -- resolve all credentialsSecretRef fields (DB, Cache, Kafka SASL, S3). - Connectivity probes -- TCP probe to DB, Cache, Kafka; HTTP probe to OIDC well-known endpoint; S3 ListBuckets. Each sets its own status condition with descriptive error messages. Failures are independent.
On all probes passing, transition status.phase from Validating to Migrating.
